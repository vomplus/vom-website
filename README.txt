봄플러스텍 홈페이지 파일

1. index.html 을 더블클릭하면 로컬 브라우저에서 미리 볼 수 있습니다.
2. 실제 홈페이지에 게시하려면 index.html, style.css, script.js 를 웹호스팅의 공개 디렉터리(예: public_html)에 함께 업로드하세요.
3. 도메인 연결 및 HTTPS 인증서는 웹호스팅 관리자에서 설정하세요.
4. 회사소개서 내용에 기반해 작성했습니다. 공개 전 회사명/연혁/서비스 거점/주소/거래처 정보 등을 검수하세요.
5. 본 버전은 정적 소개형 사이트이며 관리자 로그인, 문의 저장, 서버 기능은 포함하지 않습니다.
